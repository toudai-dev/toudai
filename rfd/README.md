# Requests for Discussion

Lighthouse uses the [Textbin RFD
format](https://github.com/chaba-dev/textbin/tree/main/rfd) to keep architecture,
decision context, implementation progress, and measured experiments together.

Each four-digit directory contains an umbrella proposal in `README.adoc`,
flat `<section>.adoc` design documents with corresponding
`<section>-impl.adoc` implementation plans, and an `experiments/` directory.
Each checklist item has one owning plan; the umbrella links to all pairs.
Legacy unsplit proposals may retain `IMPLEMENTATION.org` or `IMPLEMENTATION.md`.
Proposals move through `prediscussion`, `ideation`, `discussion`, `published`,
`committed`, or `abandoned`. Checkboxes belong in the implementation companion,
not in the proposal.
