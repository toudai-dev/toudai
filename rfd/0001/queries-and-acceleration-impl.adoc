== PoC-required: raw query semantics

Depends on the versioned event contract, authenticated query scope, and the
acceptance plan's materialized fixture. Validate raw results against independent
fixture expectations before using them as acceleration comparison anchors.

* [ ] Define the event filter, grouping, time-series, heatmap, percentile, and raw-result query contract.

* [ ] Compare companion-type and tagged-value Map encodings against the typed fixture; verify lossless canonical round-trip, type-sensitive filters/groups, numeric rather than lexical ordering, presence semantics, aggregate type errors/overflow, and lossless response encoding; record storage and execution cost before selecting the PoC DDL.
+
Experiment 019 compared both encodings on a deterministic typed fixture with
independently computed expectations. Both satisfy the listed semantics when a
mapping step supplies the types; the companion type Map adds about 1.2% of the
serving Map bytes and keeps the stock serving strings, while the tagged-value
Map adds about 4.7% and more group-by work. The versioned typed canonical
payload round-trips losslessly and matches the companion-type serving
representation. Aggregate overflow is rejected by the harness query prototype
after `Int128` accumulation; plain `sum(Int64)` wraps, so the query layer must
guard it. Lossless response encoding and PoC DDL selection remain open (the
service layer and the decision record own them). See
link:experiments/019-typed-canonical-storage.adoc[Experiment 019].

* [ ] Implement a planner that chooses raw, projection, metadata, or aggregate paths without changing query semantics.

* [ ] Implement independent accuracy, path, and completeness controls; table-test exact rollup selection, raw approximate execution with permission, unknown source coverage, missing execution shards, and budget failures without silent downgrade.

* [ ] Preserve and validate known/unknown sampling metadata and provenance; test identical retained events with different declared probabilities produce unchanged observed-event aggregates and explicit adjustment=none, while invalid metadata and unsupported correction requests never produce falsely corrected results.

* [ ] Return plan diagnostics including selected storage path and approximation mode.

* [ ] Define ingestion watermarks, expected shard coverage, and complete versus bounded-latency execution independently of exact versus approximate math.

* [ ] Execute the required raw query shapes against the deterministic fixture; verify expected rows/aggregates and diagnostic accuracy, including rejected and failed requests.

* [ ] Verify derived storage remains within the agreed amplification budget.
